# Reports API and Android Java integration

## One-time database update

Import `api_tokens_migration.sql` in phpMyAdmin while the `tapsihan_inventory` database is selected. This adds revocable, expiring mobile bearer-token storage. Existing website sessions continue to work.

## Shared Reports endpoint

- `GET /api/reports.php?from=2026-10-01&to=2026-10-31&period=custom` returns JSON.
- `GET /api/reports.php?from=2026-10-01&to=2026-10-31&period=custom&format=xlsx` downloads a real `.xlsx` workbook.
- `GET /api/reports.php?from=2026-10-01&to=2026-10-31&period=custom&format=pdf` downloads a PDF file.

Both the website and Android app use this endpoint. Date values are `YYYY-MM-DD`; `from` must not be after `to`. Reports are calculated from MySQL tables (`stock_counts`, `restocks`, `wastes`, `portion_mappings`, `portion_mapping_ingredients`, `inventory_items`). The existing business rule estimates portions from the main meat/fish ingredient's stock consumption divided by `used_per_order`, and multiplies portions by the saved selling price. A missing stock count means sales for that item/date cannot be measured reliably.

The Excel export uses PHP's `ZipArchive` extension. If it reports that ZipArchive is unavailable, enable `extension=zip` / `php_zip` in the active `php.ini` and restart Apache. PDF export is generated by PHP and does not use browser printing.

## Mobile login

POST JSON to `/api/auth/login.php` with `Content-Type: application/json`:

```json
{
  "identifier": "owner",
  "password": "YOUR_PASSWORD",
  "client": "mobile"
}
```

A successful response includes `token`, `tokenType: "Bearer"`, `expiresIn: 2592000` (30 days), and the user details. The raw token is returned only at login; the database stores its SHA-256 hash. Keep the token in Android's secure storage and never log it. Send it on every protected request:

`Authorization: Bearer YOUR_TOKEN`

For logout, POST to `/api/auth/logout.php` with the same Authorization header. The token is revoked. Inactive accounts, expired tokens, and revoked tokens are rejected.

## Android Studio (Java) request pattern

Use your server's reachable base URL, not `localhost` from a physical phone. The Android emulator can usually reach the development PC at `http://10.0.2.2/PROJECT_FOLDER/`; a physical phone needs the PC's LAN IP and both devices on the same network. Use HTTPS for any deployed/public server. Add `android.permission.INTERNET` to `AndroidManifest.xml`.

Example using `HttpURLConnection` for login (run network work off the main thread):

```java
URL url = new URL(BASE_URL + "/api/auth/login.php");
HttpURLConnection conn = (HttpURLConnection) url.openConnection();
conn.setRequestMethod("POST");
conn.setConnectTimeout(15000);
conn.setReadTimeout(15000);
conn.setDoOutput(true);
conn.setRequestProperty("Content-Type", "application/json; charset=UTF-8");
JSONObject loginBody = new JSONObject();
loginBody.put("identifier", username);
loginBody.put("password", password);
loginBody.put("client", "mobile");
String body = loginBody.toString();
try (OutputStream os = conn.getOutputStream()) {
    os.write(body.getBytes(StandardCharsets.UTF_8));
}
int status = conn.getResponseCode();
InputStream stream = status >= 200 && status < 300
        ? conn.getInputStream() : conn.getErrorStream();
StringBuilder responseText = new StringBuilder();
try (BufferedReader reader = new BufferedReader(new InputStreamReader(stream, StandardCharsets.UTF_8))) {
    String line;
    while ((line = reader.readLine()) != null) responseText.append(line);
}
JSONObject response = new JSONObject(responseText.toString());
if (status == 200 && response.optBoolean("ok")) {
    String token = response.getString("token");
    // Save token securely; then attach Authorization: Bearer <token> to API requests.
} else {
    String error = response.optString("error", "Login failed");
}
conn.disconnect();
```

For a Reports request, use the same `HttpURLConnection` pattern with GET and set:

```java
conn.setRequestProperty("Authorization", "Bearer " + token);
conn.setRequestProperty("Accept", "application/json");
```

For `.xlsx` or `.pdf`, request the same URL with `format=xlsx` or `format=pdf`, set the bearer header, and save the response bytes to a file. Do not add the raw token to a URL or query string.
