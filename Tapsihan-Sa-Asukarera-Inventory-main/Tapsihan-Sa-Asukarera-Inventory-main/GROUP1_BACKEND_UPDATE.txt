GROUP 1 BACKEND CONNECTION UPDATE

Added module-local PHP endpoints:
- Shift/shift.php
- Stockcount/stock-counts.php
- Restock/restocks.php
- Waste_spoilage/waste_spoilage.php

The endpoints use the existing includes/bootstrap.php session, login, CSRF, PDO and JSON helpers. GET requests load module records from MySQL. POST requests save records and map the browser's RM-xxx item codes and SHIFT-... shift codes to database IDs. Restocks and waste records retain their existing module calculations; stock count calculations in JavaScript were not rewritten.

Setup:
1. Extract this ZIP into your existing project folder, allowing the included files to overwrite the same files.
2. Keep using your existing config/config.php database settings.
3. Run through XAMPP/Apache and MySQL (do not open the HTML files directly with file://).
4. Log in, start a shift, then test restock, waste, stock count, and shift closing.
5. Check the shifts, shift_opening_stocks, restocks, wastes, stock_counts, and inventory_items tables in phpMyAdmin.

Notes:
- The first successful save synchronizes the browser's current module state to MySQL. The pages also request saved module records from their PHP endpoint on load.
- These changes were syntax-checked with PHP's lint and Node's JavaScript parser. They were not exercised against your live XAMPP database in this environment, so please follow the test steps before treating the modules as verified.
